# FlutterMovenet

Riverpod와 Melos를 사용하는 기능 기반 Flutter 자세 코칭 앱입니다.

```bash
flutter pub get
dart run melos run generate
dart run melos run analyze
dart run melos run test
flutter run
```

실시간 카메라와 앨범 영상에서 온디바이스 포즈를 감지하고, 풀업·스쿼트·푸쉬업의 전체 반복 횟수와 종목별 코칭을 제공합니다. ML Kit 플러그인 제약에 따라 Android/iOS 실제 기기를 지원합니다.
